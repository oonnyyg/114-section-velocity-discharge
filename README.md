# 河道断面流量核算工具

仅使用 Python 标准库，从各条测量垂线的分层流速计算断面面积、净流量与分段贡献，回流保留负号。

## 单位

- 长度（横向位置、水深）：米 (m)
- 流速：米每秒 (m/s)
- 面积：平方米 (m²)
- 流量：立方米每秒 (m³/s)

## 输入格式（JSON）

```json
{
  "sections": [
    {
      "id": "S1",
      "verticals": [
        {"position": 0.0, "depth": 0.0},
        {"position": 5.0, "depth": 1.2,
         "samples": [
           {"rel_depth": 0.0, "velocity": 0.8},
           {"rel_depth": 0.5, "velocity": 0.6},
           {"rel_depth": 1.0, "velocity": 0.2}
         ]},
        {"position": 10.0, "depth": 0.0}
      ]
    }
  ]
}
```

校验规则：

- 每个断面至少两条垂线；`position` 严格递增；`depth` 非负；两岸端点水深为零。
- 所有数值必须为有限数。
- 有水垂线（`depth > 0`）必须携带 `samples`，且采样覆盖相对深度 0（水面）与 1（河底），相对深度不得重复、不得超出 [0, 1]。
- 干垂线（`depth == 0`）不带采样，平均流速约定为零。

## 插值与积分假设

- **垂线平均流速**：相邻采样点之间流速随相对深度线性变化，平均流速为线性插值在 [0, 1] 上的积分（按采样间距加权的梯形积分），不对不等距采样直接取算术平均。
- **分段流量**：相邻垂线之间水深与垂线平均流速分别随横向位置线性变化，分段流量为两者乘积（二次多项式）在分段宽度上的解析积分，而不是把端点流量直接作梯形积分。干-湿交界段因此为 `宽度 × 湿端水深 × 湿端平均流速 / 3`。
- 流速可正可负，回流段的负流量直接计入净流量，不做截断。
- 全干断面面积与流量均为零，平均流速输出 `null` 并在 `note` 中说明原因。

## 使用方法

```bash
python -m section_flow input.json --csv segments.csv --json summary.json
```

- CSV 分段明细：每个断面每相邻垂线一段，含左右位置、水深、平均流速、湿面积与有符号流量。
- JSON 汇总：每个断面的各垂线平均流速、总面积、净流量、断面平均流速（全干为 `null`），以及独立报告的无效断面错误；单个断面无效不影响其他断面。
- 存在有效断面时退出码为 0，全部无效时为 1。
