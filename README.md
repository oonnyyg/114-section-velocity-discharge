# 河道断面流量核算工具

仅使用 Python 标准库，从各测量垂线的分层流速采样计算断面湿面积、
净流量与分段贡献，回流保留负号。

## 单位与插值假设

- 长度：米（m）；流速：米每秒（m/s）；面积：平方米；流量：立方米每秒。
- 流速采样以相对深度表示：0 为水面，1 为河底。
- 同一垂线内，流速随相对深度**线性变化**，垂线平均流速为剖面在
  [0, 1] 上的积分（分段梯形积分），对不等距采样严格成立，
  不做算术平均。
- 相邻垂线之间，水深与垂线平均流速分别随横向位置**线性变化**，
  分段流量为两者乘积的解析积分：
  `Q = w·(2·h0·u0 + h0·u1 + h1·u0 + 2·h1·u1) / 6`，
  而不是对端点流量做梯形积分。
- 干垂线（水深为零）不带采样，平均流速约定为 0。
- 全干断面面积与流量均为 0，平均流速输出 `null` 并附说明，不除零。

## 输入格式（JSON，UTF-8）

```json
{
  "sections": [
    {
      "id": "S1",
      "verticals": [
        {"x": 0.0, "depth": 0.0},
        {"x": 2.0, "depth": 1.5, "samples": [[0.0, 0.8], [0.5, 1.0], [1.0, 0.6]]},
        {"x": 4.0, "depth": 0.0}
      ]
    }
  ]
}
```

校验规则：数值必须有限；横向位置严格递增；水深非负；两岸端点水深为零；
有水垂线的采样必须覆盖相对深度 0 与 1，采样位置严格递增且不越界。
单个断面无效时独立报告（JSON 的 `invalid_sections` 与标准错误），
不影响其他断面的核算。

## 使用方法

```bash
python -m section_discharge 输入.json --csv 分段明细.csv --json 汇总.json
```

不带 `--csv` / `--json` 时，结果输出到标准输出。命令可重复运行，
结果一致。

## 输出

- CSV 分段明细：断面标识、分段序号、左右横向位置、宽度、湿面积、有符号流量。
- JSON 汇总：单位说明、各断面湿面积 / 净流量 / 断面平均流速、
  各垂线平均流速（含原始断面标识），以及无效断面列表。
